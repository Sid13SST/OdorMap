Odor descriptors, predicted from a molecule’s structure.

OdorMap takes one molecule as a SMILES string and scores 113 odor descriptors from the Leffingwell catalog, such as vanilla, citrus or sulfurous. It is a small baseline: Morgan fingerprints and logistic regression, with its accuracy and its failure modes measured and written down.

From a SMILES string to ranked descriptors

Four steps, all on CPU, all in plain scikit-learn and RDKit. Hyperparameters are fixed at scikit-learn defaults; nothing was tuned on any split.

  1. Parse

    RDKit reads the SMILES and rejects strings it cannot parse.

    COc1cc(C=O)ccc1O

  2. Fingerprint

    Morgan fingerprint, radius 2, 2,048 bits. It is non-chiral, so stereoisomers look identical.

    0010…0100 (2,048 bits)

  3. Score

    113 one-vs-rest logistic regressions, one per descriptor, each with balanced class weights.

    113 independent scores

  4. Rank and flag

    The top ten are shown, and the molecule is checked against the training set by canonical SMILES.

    vanilla 0.999 · in training data

Measured performance, and where it drops

Ranking quality on two splits

Macro ROC-AUC by evaluation split
SplitMacro ROC-AUC
Random, stratified 5-fold CV0.8633 ± 0.0032
Bemis-Murcko scaffold split, 80/200.7561

In the random split, molecules that share a ring scaffold can sit on both sides, so the model is often scored on close relatives of what it saw. The scaffold split keeps every scaffold on one side, which is closer to meeting a new chemical family. Macro ROC-AUC drops by 0.107.

Scaffold split: one seed, so no variance estimate, and its test set contains no acyclic molecules. Full tables in results/baseline.md.

Honest limitations

The same warnings the app shows next to every prediction, plus the caveats of the evaluation itself.

  • Known molecules can be memorized

    The model behind the app and the command line is trained on all 3,522 Leffingwell molecules. For a molecule in that set, the scores may reflect memorized catalog labels, not generalization.

  • New molecules are unvalidated

    For a molecule not in the dataset there is no ground truth to check against, and close structural analogs may still be in the training set.

  • Scores are model confidence

    A score of 0.8 does not mean an 80% chance the descriptor applies. On held-out scaffolds, the 0.9–1.0 score bin was positive only 46% of the time.

  • Catalog descriptors only

    It predicts the catalog’s descriptors for single pure molecules. It does not model real-world odor perception, mixtures or concentration effects.

  • Stereochemistry is ignored

    The fingerprint is non-chiral, so stereoisomers get identical scores, even where the catalog lists them differently (as it does for the forms of limonene).

  • The scaffold estimate is a single split

    The 0.7561 comes from one seed with no variance estimate, and that test set has no acyclic molecules, so it differs from the full dataset.

Data, license and attribution

Trained on the Leffingwell Odor Dataset: expert-labeled odor descriptors for single molecules, curated by Sanchez-Lengeling et al. (2019, arXiv:1910.10685) from the Leffingwell PMP 2001 database of John C. Leffingwell and Associates. OdorMap downloads it from the pyrfume-data mirror; the dataset itself is not stored in the repository.

Canonical record: Zenodo, DOI 10.5281/zenodo.4085097. License: CC-BY-NC 4.0. The labels were joined and used for training, not modified.

Non-commercial use only. Because the dataset is CC-BY-NC 4.0, OdorMap, its trained models and its demo app inherit that restriction.

Python 3.10 or later, CPU only.

cd OdorMap
pip install -r requirements.txt
python scripts/fetch_data.py
python scripts/run_baseline.py
streamlit run app.py
