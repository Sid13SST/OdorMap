# Baseline: Morgan fingerprints + one-vs-rest logistic regression

Generated by `python scripts/run_baseline.py` (seed=0, CPU only, total wall time 36s).

## Setup

- Features: Morgan fingerprint, radius 2, 2048 bits (RDKit), computed on `nonStereoSMILES`.
- Model: scikit-learn `OneVsRestClassifier(LogisticRegression(C=1.0, class_weight='balanced', solver='liblinear'))` — one binary classifier per label (138 labels), each with per-label balanced class weights.
- Hyperparameters are fixed (sklearn default C); no tuning was done on any split.
- Macro ROC-AUC and mAP are computed over labels that have both positives and negatives in the evaluated test set; skipped labels are counted below. Macro F1 uses a fixed 0.5 threshold over all labels.

## (b) Bemis-Murcko scaffold split (80%/20%)

Molecules are grouped by Bemis-Murcko scaffold; whole groups are assigned to train or test so **no scaffold appears in both** (asserted in the script and in `tests/test_splits.py`). Groups are shuffled with the seed and filled into test up to the target size. The single largest group — the acyclic (empty) scaffold — is forced into train, so the scaffold test set contains **no acyclic molecules**; this is a property of this split, not just a leakage control, and makes the test distribution differ from the full dataset.

## Why is macro F1 low? (scaffold test set, measured)

Macro F1@0.5 is low on both splits. A common explanation is label imbalance (rare descriptors). We measured how per-label F1@0.5 on the scaffold test set relates to how many positives each label has, using Spearman rank correlation over all 138 labels.

| Comparison (per label, n = labels) | Spearman ρ | p-value |
|---|---|---|
| F1@0.5 vs # positives in the **test** set (n=138) | **0.539** | 9.4e-12 |
| F1@0.5 vs # positives in the **train** set (n=138) | 0.315 | 1.7e-04 |
| ROC-AUC vs # positives in the test set (n=138, context) | -0.035 | 6.8e-01 |

| Test positives per label | Labels | Mean F1@0.5 |
|---|---|---|
| 1–9 | 36 | 0.085 |
| 10–29 | 66 | 0.142 |
| ≥ 30 | 36 | 0.302 |

Macro precision@0.5 = 0.161, macro recall@0.5 = 0.203.

**What the data shows (measured):** per-label F1 is moderately, positively rank-correlated with label frequency in the test set (ρ = 0.54) and more weakly with frequency in the training set (ρ = 0.31). So rarer labels do tend to have lower F1, but frequency explains only part of the variation, and the low F1 is not confined to rare labels: even labels with ≥ 30 test positives average well below 0.5.

**What it does not show:** per-label ROC-AUC is essentially uncorrelated with frequency (ρ = -0.04), so rare labels are *ranked* about as well as common ones. Our hypothesis (not tested here) is that the F1–frequency association comes mostly from the fixed 0.5 threshold and prevalence: with few true positives, the same false-positive rate yields much lower precision, and labels with only a handful of test positives give very noisy F1. Low macro F1 should therefore not be read as simply "caused by imbalance": the untuned threshold and over-confident scores (see `results/calibration.md`) are plausible contributors too, and these factors have not been separated.
