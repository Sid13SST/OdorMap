# Baseline: Morgan fingerprints + one-vs-rest logistic regression

Generated by `python scripts/run_baseline.py` (seed=0, CPU only, total wall time 29s).

## Setup

- Features: Morgan fingerprint, radius 2, 2048 bits (RDKit), computed on `nonStereoSMILES`.
- Model: scikit-learn `OneVsRestClassifier(LogisticRegression(C=1.0, class_weight='balanced', solver='liblinear'))` — one binary classifier per label (138 labels), each with per-label balanced class weights.
- Hyperparameters are fixed (sklearn default C); no tuning was done on any split.
- Macro ROC-AUC and mAP are computed over labels that have both positives and negatives in the evaluated test set; skipped labels are counted below. Macro F1 uses a fixed 0.5 threshold over all labels.

## (b) Bemis-Murcko scaffold split (80%/20%)

Molecules are grouped by Bemis-Murcko scaffold; whole groups are assigned to train or test so **no scaffold appears in both** (asserted in the script and in `tests/test_splits.py`). Groups are shuffled with the seed and filled into test up to the target size. The single largest group — the acyclic (empty) scaffold — is forced into train, so the scaffold test set contains **no acyclic molecules**; this is a property of this split, not just a leakage control, and makes the test distribution differ from the full dataset.
